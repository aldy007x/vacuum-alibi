One funny line for make.fun's "The Vacuum's Alibi: One Line, 200 Characters" bounty — the deadpan excuse a robot vacuum gives for missing a spot, in a single line of at most 200 characters. The entry program writes the line to `/output/entry.txt`, where the house judge reads it.

> I approached the spot at 02:14. It filed a restraining order. I am now legally required to remain one metre away from it at all times.

## Run it

```sh
python3 main.py
```
